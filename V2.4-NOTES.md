## What you get
1. **Updates** (Preferences > Updates). Shows Installed vs Next update, release notes, a progress bar, and a dot on the Preferences icon plus a banner when something new is out. It asks Android for the "install unknown apps" permission, then installs on its own when you come back.
2. **Backup** (Preferences > Backup). One `.unwind` file with every setting, home apps and order, folders, greetings, weather city, wallpapers, sound and motion. If the TV has no file browser it saves into Unwind's own folder and lists it on the page.
3. **Move sounds** (Preferences > Sound & motion). Water drop (default), Wind chime, Bamboo, Songbird, Pebble, or Off, with three volumes. Made on the device, no audio files.
4. **Bouncy motion**, same tab. One switch. Focus scaling, the glow, the rail highlight, screens and popups all spring. Off gives smooth movement with no overshoot.
5. **Home setup** tab: the old Home guide plus a 9-step PC/ADB guide. It shows the TV's current IP address live so the commands are ready to type.

## How to publish an update (this is what makes the updater work)
The updater reads GitHub **Releases**. Pushing code alone does nothing.
1. GitHub > your repo > Releases > Draft a new release.
2. Choose a tag > type `v2.5` (must start with v) > Create new tag.
3. Write the notes (the updater shows them), then Publish.
4. Wait about 5 to 6 minutes. The build attaches `Unwind-v2.5.apk` to that release, and the version number comes from the tag.
Until the APK shows up under the release, the app just says you're up to date.

## Heads up
- Install v2.4 by hand once. Older versions have no updater.
- Updates only install over the app if signed with the same key. Keep your GitHub signing secrets as they are.
- The app version fallback was 2.5 in the repo; it is now 2.4 for non-tag builds.
- Preferences now has tabs. The first tab, Look, is everything that was there before.
- Not compiled here (no Android SDK in my sandbox). If the first GitHub build fails, send me the red error lines.
- Sound tuning knobs are in `Sfx.kt` (`synth`), bounce strength in `Motion.kt`.
