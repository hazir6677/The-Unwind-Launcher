# Unwind v2.5: what changed and how to ship it

## Upload these files (same flat layout as your repo)
New: `Widgets.kt`, `DockMenu.kt`
Changed: `Model.kt`, `Motion.kt`, `Components.kt`, `Screens.kt`, `PrefTabs.kt`, `MainActivity.kt`, `AppData.kt`, `AndroidManifest.xml`, `app-build.gradle.kts`, `CHANGELOG.md`
Nothing to delete. The build workflow already picks up every `.kt` file in the root.

## What you get
1. **Long-press menu** on home apps: App info, Move, Remove from Home, Uninstall.
2. **Move mode**: arrows carry the app, OK drops it, Back cancels. Saved in the same `favs` setting as before, so backups keep the order.
3. **Home widget tab** with Unwind Greetings, Month calendar, Clock (digital or analog), Weather, Date and Nothing. The greeting editor moved here from Look.
4. **Top-bar clock hides** when the Clock widget is on.
5. **Launch animation** (zoom and fade out, ease back in), switchable under Sound & motion.

## Added after the first v2.5 drop
- **Search merged into All apps.** Search page removed; the All apps and Favorites pages get a search bar on top. Dock is now 3 buttons.
- **Top-right bar** no longer has a search button.
- **Clear style** lost its outline and edge band.
Changed in this round: `Model.kt`, `Components.kt`, `Screens.kt`, `Folders.kt`, `MainActivity.kt`, `ClearGlass.kt`, `CHANGELOG.md`, `readme.md`.

## Heads up
- Uninstall needs the new `REQUEST_DELETE_PACKAGES` line in the manifest (included).
- Not compiled here (no Android SDK in my sandbox). Braces and imports were checked by hand. If the GitHub build goes red, send me the red error lines.
- Widgets scale down to fit the space above the row, so they stay inside the screen on any TV size and in Stacked layout.
- To publish: GitHub > Releases > new tag `v2.5`. The updater and What's New read from that tag and `CHANGELOG.md`.
